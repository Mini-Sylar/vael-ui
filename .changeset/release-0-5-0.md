## Breaking changes

| What                          | Before                                        | After                                         |
| ----------------------------- | --------------------------------------------- | --------------------------------------------- |
| Vue                           | any 3.6 release candidate                     | `3.6.0-rc.13`, installed with `--save-exact`  |
| `motionCss` is renamed        | `:motion-css="false"`                         | `:motion="false"`                             |
| `beforeClose` is only a guard | `(done) => …`, `cancelClose()`                | return `true`, `false` or a promise of either |
| Exit animations               | run in `beforeClose`                          | a `motion: { leave }` hook                    |
| List events are removed       | `@card-leave`, `@row-enter`, `@chip-leave`, … | `motion: { enter, leave }`                    |
| Button colors                 | `background`, `border-color`                  | `--ui-button-bg`, `--ui-button-border`        |
| List hover colors             | `.ui-menu-item:hover { background: … }`       | `--ui-indicator-bg`                           |
| Spring helpers move           | `useSpringValue` from `'vael-ui'`             | from `'vael-ui/motion'`                       |

The `motionCss` rename also covers `ConfigProvider`, `useCollapse`, `useSortable` and `useSortableGroup`. Chip hooks go under `motion.chips` and CommandPalette's rows under `motion.items`. `createSpring`, `stepSpring` and their types move with `useSpringValue`.

```ts
{
  // A guard that asks before closing
  beforeClose: () => !dirty.value || confirmAction({ title: 'Discard changes?' }).result,
  // A close animated by a hook
  motion: { leave: ({ panel }) => gsap.to(panel, { opacity: 0 }) },
}
```

## The motion system

0.5.0 rebuilds animation around one `motion` prop and one engine, adds four components, gives every list a sliding hover highlight, and documents each component's keyboard and screen reader support. The [motion guide](https://vael-ui.dev/motion) covers the system in depth. The engine animates `transform` and `opacity` with CSS transitions and Web Animations, and a page loads only the parts it uses.

What you animate your own elements with imports from `vael-ui/motion`, in both builds: `v-animate`, `animate`, `useAnimate`, `useMotion`, `useScrollProgress`, `settled`, the spring helpers and the motion types. A Vapor component uses `vAnimateVapor`, as with `vTooltipVapor`; with the `vapor` export condition, `vAnimate` is already the Vapor form. Each component's own type, such as `DialogMotion`, imports from `vael-ui` with the component.

```vue
<Dialog :motion="{ spring: 'bouncy', initial: { panel: { opacity: 0, y: 8 } } }" />
<Dialog :motion="{ leave: ({ panel }) => gsap.to(panel, { opacity: 0 }) }" />
```

| Feature                  | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `motion`                 | `false` turns motion off. An object sets part values (`initial`, `exit`), timing and `enter`/`leave` hooks. Each component exports its type: `DialogMotion`, `SelectMotion`, …                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Timing                   | A spring by name (`snappy`, `smooth`, `bouncy`, `gentle`) or `{ damping, response }`, or a `duration` and `easing`. Both take token names, such as `'enter'`, `'out'` or `'bounce'`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Hooks                    | Return what GSAP, motion or `element.animate()` returns, or a promise. vael-ui waits for it, and cancels it if you reverse partway                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Lists                    | Toaster, Timeline, FileUpload, SpeedDial, DataTable rows, CommandPalette items and chips take `stagger` and `leaving: 'pop' \| 'hold'`, and the other items slide to their new places                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Overlays                 | `morph: 'trigger'` grows an overlay out of what opened it. `linked` moves other elements with it, `surface` draws a gooey Popover, and `exitOrder` and `resize` tune the close. `stagger` brings a dialog's header, body and footer in one after another                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| States                   | Looks for `hover`, `active`, `focus`, `checked`, `invalid` and more, per part, with keyframes (`null` first starts from where it is), `repeat`, `repeatDelay`, `repeatType: 'mirror'` and springs. Indicators take a `spring`, `stretch`, `squash` and a `move` hook. A state's `replay` plays its keyframes again while it's on (a second wrong code shakes again)                                                                                                                                                                                                                                                                                                                                                                                                  |
| Callbacks                | `onAfterEnter` and `onAfterLeave` run once something has come in or left: an overlay, each list item, a state, your own elements. `onStart` runs as your element starts moving, `onAfterSwap` after a swap, `onAfterMove` after a `layout` slide or an `animate` change, and `onRepeat` as each repeat starts. With nothing to play, as with motion off, they run at once. `v-animate`'s states take `onAfterEnter` and `onAfterLeave` too                                                                                                                                                                                                                                                                                                                           |
| `ConfigProvider`         | `motion` styles the whole app by role or by component, sets one spring for everything (a `drawer` key styles Drawer apart from Dialog), names `presets` for `v-animate`, and can run it all through your own `engine`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `v-animate`              | Animates your own elements: entrances (`.rise`, `.pop`), exits (on `v-show` too), `stagger`, `states` (with `inView`), `layout` (place and size), `layoutId`, `.size`, `animate`, `progress`, `when: 'visible'` with a `viewport`, 3D turns (`rotateX`, `rotateY`, `perspective`), one-axis `scaleX` and `scaleY`, `pathLength` drawing, and your own `enter` and `leave` hooks. `replay` plays `animate`'s keyframes again from the start, `inView` can take its own `viewport`, and `after` can wait on an element already on the page. Pages: on a routed component, `v-animate:page` crosses the old and new page, and `swap: 'wait'` brings the new one in once the old has gone. `stagger: 'center'` and `'edges'` go by where each element sits across a grid |
| Scroll                   | `useScrollProgress()` gives the page's scroll, or an element's way through the screen, as a ref from 0 to 1; pass it to `progress` as a getter and the scroll never re-renders your component. `useTween(source)` is a number that eases to each new value, for totals and percentages                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| From code                | `animate(el, values, options)` plays the same values and timing from your code (await it, or `pause`, `reverse`, seek and change its `speed`), following the app's spring and reduced motion; `useAnimate()` scopes selectors to a component and stops its runs on unmount. `useAnimate(useTemplateRef('row'))` scopes it to a template ref                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Server rendering         | `v-animate` entrances are written as CSS on the server and never replay on hydration. The Nuxt module registers `v-animate`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `useMotion`, `settled()` | The same `motion` prop for your own components, `false` included. `await settled()` waits for every animation, in tests; `await settled(el)` waits for one element's                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Development              | `data-motion` names where an element's motion came from, opens and closes show in the Performance panel, and a CSS transition that fights the motion warns                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

vael-ui skips animations in a hidden tab, in a view restored by `KeepAlive`, past the 24th element appearing at once without a `stagger`, and on recycled virtual rows. Under reduced motion, hooks don't run unless you set `reducedMotion: 'run'`.

## Changes to built-in animations

Every built-in animation stays under 300 ms, eases out, closes faster than it opens, and keeps only its fade under reduced motion. Drawers, a dialog grown from its trigger and AnimatedNumber's roll take longer, because they travel further.

| Component                                            | Change                                                                                      |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Popover, Menu, Tooltip                               | Panels grow from the exact center of their trigger                                          |
| Tooltip                                              | No jitter or blur. It glides between triggers and follows a moving one                      |
| Button                                               | The box and its contents scale together on press, and sizes snap to whole pixels            |
| Tree, TreeSelect                                     | Folders fold on a spring, and reverse if you click again partway                            |
| Sortable                                             | Rows spring into place in every case                                                        |
| Dock                                                 | Touch magnifies, magnification follows the motion spring, and the bar widens with its items |
| Tour                                                 | The callout travels with the spotlight                                                      |
| Slider                                               | A value set from your code glides the thumb there                                           |
| Drawers, BottomSheet                                 | Close in 350 ms instead of 500 ms                                                           |
| Chevrons, clear buttons                              | Turn and fade in step with their panel                                                      |
| Calendar, Collapsible, Accordion, Message, DataTable | No clipping or jumps while content grows or months switch                                   |
| Switch, Checkbox, Radio                              | Give feedback when pressed                                                                  |

## Accessibility

Every component page now has an Accessibility section with its keys, the WAI-ARIA pattern it follows, its roles and the labels you provide. The main changes:

- A modal Dialog, Drawer, BottomSheet or CommandPalette makes the rest of the page inert. Menu, ContextMenu and Tour name themselves and return focus.
- Keyboard and naming fixes in Tree, CascadeSelect, Select with `filter`, DataTable with row selection, CommandPalette and Calendar's month and year views. Long virtual lists announce each option's position.
- Fields keep your `aria-describedby` and add the Field's description and error to it. PasswordInput, FileUpload, Slider, Knob, Dial and Rating report invalid and changed states.
- In right-to-left layouts, the arrow keys follow the screen in Tabs, Toolbar, Menu, Tree, Rating, Dock, Slider and Resizable.
- The new announcements are translatable through `ConfigProvider` messages.

## Other changes to check when upgrading

- A Drawer with `side="top"` or `"bottom"` spans that edge and slides in from it, as left and right do; before, it was a card that rose a few pixels. A Dialog's `position="top"` / `"bottom"` is unchanged.
- Closed Collapsible and Accordion content is `hidden="until-found"` instead of `visibility: hidden` and `inert`.
- `toast.promise` updates its loading toast in place, so it keeps one id and Toaster's `success` and `error` states animate it, instead of replacing it with a new toast.
- `force-mount` only keeps content mounted. Animate content kept this way with `motion` hooks.
- `motion="false"` on Select, Combobox, CascadeSelect, DatePicker, TreeSelect and CommandPalette also opens and closes the panel at once.
- CascadeSelect's menu is at least as wide as its field, up to 16rem, so on a long field the next level still opens close by. The levels opening beside it keep their own width.
- InputNumber stepped from empty starts at 0, as a native number input, then keeps within `min` and `max`: with `min: 5` and `step: 5`, the first press gives 5, not 10.
- `--ui-indicator-bg` is no longer set on `:root`. Read it as `var(--ui-indicator-bg, var(--ui-muted))`.
- Timeline's hooks receive the step's `marker`, `connector` and `content`, replacing the removed `TimelineItemParts` type.
- `messagesKey` carries what a `ConfigProvider` hands down, `{ messages, i18n }`, instead of the merged catalog, so each component ships only its own strings. `useUiMessages()` still returns the whole catalog.

These components render different DOM, which your selectors or tests may rely on. Their props, slots and events are unchanged.
